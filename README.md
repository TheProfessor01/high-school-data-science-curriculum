# Project-Based Data Science Curriculum

## Overview

This repository contains a project-based data science curriculum designed to take complete beginners from no programming experience to building and analyzing data using Python.

The course emphasizes:
- hands-on coding
- real-world problem solving
- structured progression from fundamentals to application

Rather than focusing on theory alone, students learn by building, debugging, and analyzing data through guided projects.

---
## Featured Project: Student Performance Analyzer

Students act as data analysts for a school and use Python to analyze student performance data.

This project demonstrates:

- working with structured data using lists and dictionaries
- applying conditional logic
- building reusable functions
- looping through records
- calculating the percentage of students classified as “At Risk”
- communicating insights from data

## Problem

Many students are introduced to programming and data science through disconnected exercises that do not reflect how these skills are used in real-world contexts.

This curriculum was designed to address that gap by:
- integrating tools used in industry (GitHub, Jupyter Notebooks)
- emphasizing debugging and problem-solving
- introducing data analysis early through applied projects

## How to Use This Repository

Each unit contains:
- slide decks as PDFs
- guided Jupyter Notebooks
- activities and mini-projects

The notebooks are designed to run in Jupyter Notebook, Google Colab, or GitHub Codespaces.

---

### Unit 1: Foundations
- Introduction to data science concepts
- Git, GitHub, and Jupyter Notebooks
- Python fundamentals (variables, loops, conditionals, functions)
- Debugging strategies and error analysis
- Mini Project: Text Analysis using Python

Students progress from writing basic code to:
- processing raw text data
- cleaning and transforming data
- analyzing word frequency and patterns

---

### Unit 2: Python Programming & Application

- Writing structured Python programs
- Advanced use of conditionals, loops, and functions
- Working with lists and dictionaries to organize data
- Debugging and refining multi-step logic
- Building interactive programs (e.g., calculators, chatbots)

Students move beyond syntax and begin to:
- design their own programs
- break down problems into logical steps
- apply programming concepts to real scenarios

This unit emphasizes the transition from learning Python to using Python as a problem-solving tool.

---

## Additional Project: Text Analysis

In the Unit 1 mini-project, students:

- import and read a text file
- clean and preprocess text (lowercase, remove punctuation)
- split text into structured data (lists)
- use dictionaries to count word frequency
- sort and analyze the most common words

This project introduces a simplified data pipeline:
Raw Text → Cleaning → Structuring → Analysis → Insight

## Learning Approach

This curriculum is built around a few core principles:

- Learn by doing, not copying
- Debugging is part of the learning process
- Code should be explained, not just written
- Data analysis should be introduced early
